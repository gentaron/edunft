## English

### Overview

EDU NFT is the repository reserved for NFT card metadata of the Eternal Dominion Universe (EDU). It will store metadata JSON files and smart contract resources for the character cards (C/R/SR rarity) used in the EDU card game.

### Status

📦 **Placeholder** — Currently reserved for future use. Card metadata JSON files and blockchain smart contract resources will be added in upcoming phases.
